# 🍱 Food Utopia

A Swiggy-inspired food ordering UI designed for transparency, trust, and cultural warmth.

## 🔥 Key Features
- Influencer video reviews
- Live restaurant footage
- Hygiene & safety walkthroughs
- FSSAI-certified restaurant filter
- User-friendly UI elements

## 🛠️ Tech Stack
- Figma (Design & Prototyping)
- React + Vite (Frontend)
- GitHub Pages (Deployment)

## 💡 Vision
Food Utopia blends joyful UX with radical transparency—helping users order with confidence and cultural connection.
